# Интеграция с обновлённым бэкендом

Проверено по коду `hellabanana/nabo_back`, коммит `f69fa98`, и развёрнутым API Railway 2 октября 2026. README бэкенда не использовался.

| API бэкенда | Использование во фронте |
| --- | --- |
| POST /api/search | Один запрос каталога по всем магазинам. Общий счётчик учитывает все полученные результаты; вкладки показывают позиции и количество конкретного магазина без новых запросов. Карточки показываются постепенно по 12. |
| POST /api/yandex/search | Поиск аналогов конкретного товара и подбор ингредиентов рецепта. |
| POST /api/product | Актуальная карточка по паре storeId/id; название в URL больше не обязательно для поддерживаемых магазинов. |
| POST /api/products/resolve | Кнопка «Обновить цены» в корзине, без автоматической замены выбранных товаров. |
| POST /api/cart/saveCart | Явное сохранение текущей корзины в аккаунте. |
| GET /api/cart/getCart?lat=…&lon=… | Загрузка корзины аккаунта с обновлением товаров для выбранной точки доставки. |

Браузер обращается к одноимённым Nitro-прокси (`/api/cart` для корзины). Bearer-токен добавляется сервером из существующей HttpOnly-cookie; в браузерное хранилище он не попадает. Запись проверяет Origin. Ответы 401/429 и Retry-After передаются без подмены.

Корзина аккаунта — один список: повторное сохранение заменяет предыдущий. Если локальная корзина не пустая, загрузка требует подтверждения её замены. Сохранённые списки `/saved` продолжают храниться локально; облачная текущая корзина доступна также на этой странице. Нет фонового сохранения, которое могло бы затереть корзину другого устройства.

Сохраняются исходный ID магазина, магазин, название, количество, изображение и фасовка. При обновлении или загрузке `not_found`, недоступный товар и `error` сохраняются в списке без подтверждённой цены и не входят в сумму. Количество и требования рецепта при обновлении сохраняются. Изменение точки доставки во время запроса/подтверждения запрещает применение старых данных.

Ограничения фактического API:

- Евроопт возвращает `PRODUCT_LOOKUP_UNSUPPORTED` для загрузки по ID. Карточка использует поиск по названию; обновление корзины показывает ограничение и предлагает выбор через «Заменить».
- Бэкенд хранит до 200 позиций, но сравнивает до 20. Текущий фронт сохраняет ограничение 20 позиций/99 упаковок; большая облачная корзина не обрезается и не заменяет локальную.
- Категории используются в карточке, только если бэкенд вернул их названия. Отдельного API каталога категорий нет.

Проверены модульные и HTTP-тесты новых контрактов, передача координат и Bearer, запрет чужого Origin, частичные ошибки обновления, сохранение исходных количеств. Реальные API поиска, карточки и пакетного обновления проверены на Railway. Запись корзины в реальный аккаунт пользователя не выполнялась; авторизованный контракт проверен на тестовом upstream.

Общий поиск возвращает массив `stores`, без отдельного `total` и серверной пагинации. Счётчики относятся к товарам, возвращённым API, а не ко всему ассортименту магазина. При частичной ошибке доступные результаты отображаются, общий счётчик помечается как количество в ответивших магазинах; неполный ответ не кэшируется.
