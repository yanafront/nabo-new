# Общий справочник ингредиентов

`/admin/recipes` → **Ингредиенты** (`/admin/ingredients`). Доступ только у существующих редакторов Nabo.

Справочник автоматически собирается из ингредиентов всех опубликованных рецептов и черновиков. Хранится на бэкенде `nabo-recipes` в `nabo_recipes.shared_ingredients`. Миграция версии 3 выполняется один раз при старте; настройки Railway менять не нужно. Новые ингредиенты автоматически регистрируются при сохранении рецепта.

Повторы объединяются по нормализованному названию: регистр, пробелы, Unicode, е/ё. Ограниченный список однозначных форм объединяет яйца/яйцо (включая «для смазки», «в тесто», «целиком»), огурцы/огурец, помидоры/помидор и лук/лук репчатый. Творог разных процентов, виды лука, шоколадные яйца и другие отличающиеся продукты не объединяются по совпадению фрагмента слова.

При переносе старые запросы рецептов не заменяются автоматически: если они различаются, это видно в справочнике. После подтверждения нового общего запроса он заменяется во всех связанных черновиках и опубликованных версиях. Сохраняются название для читателя, количество, единицы, точное название/фасовка товара, КБЖУ, инструкции и остальные поля. Замена не публикует другие черновые изменения. После первой общей правки этот запрос имеет приоритет при дальнейшем сохранении и создании рецептов с этим ингредиентом.

Операция атомарная, использует текущую revision и транзакционную блокировку. Версии затронутых рецептов увеличиваются: открытая старая форма не сможет незаметно вернуть предыдущие данные. Редактор получает фактически сохранённый документ. Публичный кэш обновляется в течение минуты; открытый рецепт может потребовать обновления страницы. Для изменения только одного конкретного варианта продукта используйте его отдельное точное название ингредиента; не объединяйте разные продукты вручную через общий запрос.

API (Bearer токен редактора):

- `GET /api/admin/ingredients`: уникальные записи, запрос, revision, варианты запросов, число и список связанных рецептов.
- `PUT /api/admin/ingredients/{id}`: `{ "searchQuery": "Яйца куриные С1", "revision": 1 }`, ответ `{ "revision": 2, "affectedRecipes": ... }`. id — стабильный SHA256 нормализованного ключа; не вводится вручную.

Справочник не удаляет исходные ингредиенты из рецептов: они сохраняют количества и роли, а общая запись управляет только поисковым запросом. Это не глобальный каталог продуктов магазинов.

Проверки: PostgreSQL CI проверяет перенос без повторов, права, распространение запроса, сохранение количеств/шагов, конфликт версий и приоритет общей правки при следующем сохранении рецепта. Browser tests проверяют подтверждение массового изменения, фильтрацию и закрытый доступ на desktop/mobile.
