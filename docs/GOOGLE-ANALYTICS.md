# Google Analytics 4

Поток: `G-MREKXGH3TP`. Подключён рядом с Яндекс Метрикой отдельным client-плагином. Скрипт async и загружается только после разрешения аналитики; localhost/dev исключены. После добавления Google версия согласия обновлена, пользователи выбирают аналитику снова.

Nabo вручную отправляет `page_view` после завершения навигации Nuxt, с очищенным URL без query/hash. Автоматический первый просмотр выключен через `send_page_view: false`. Страницы аккаунта и админки не учитываются. Рекламное хранение, Google Signals и персонализация отключены. При отзыве выбора устанавливается запрет сбора, обновляется Consent Mode, удаляются доступные cookies _ga* и страница перезагружается.

## Обязательная настройка потока GA4

Администратор → Потоки данных → веб-поток → Улучшенная статистика / Enhanced measurement → шестерёнка:

- В разделе просмотров страниц отключите **Page changes based on browser history events**. Иначе GA4 может повторно отправлять просмотры даже при `send_page_view: false`.
- Отключите автоматический поиск по сайту, взаимодействия с формами и прочие ненужные автоматические события. Для Nabo сейчас реализованы только управляемые просмотры. Автоматические события сервиса могут самостоятельно читать полный URL/поля, независимо от очистки наших событий.

Проверка: разрешите аналитику на production, посмотрите отчёт Realtime, выполните переход между рецептами и товарами. В Network запросы `g/collect` должны содержать нужный tid и один page_view на переход. Проверьте также отказ от аналитики, отзыв согласия и приватные страницы. До разрешения аналитики запросов Google быть не должно. GTM отдельно подключать не нужно.
