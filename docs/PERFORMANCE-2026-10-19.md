# Главная: производительность, 19 октября 2026

Изменения: `356af5c`. Проверен https://www.nabo.by/ после успешного production-деплоя Vercel. Lighthouse 13.5.0, мобильный профиль по умолчанию, Chrome headless, новая сессия каждого прогона. Никаких специальных ответов для аудитора.

## Изменения

- Убрано ожидание внешнего API рецептов при серверном рендере главной. Три рекомендации загружаются при приближении секции к экрану; предусмотрены скелетон и ошибка. Заголовок и ссылка на каталог остаются в HTML. Каталог и страницы рецептов сохраняют SSR.
- Исправлено расхождение гостевого меню при гидратации; баннер cookies сразу рендерится сервером. Согласие на аналитику по-прежнему необходимо.
- Hero получил зарезервированную геометрию. Логотипы магазинов получили явные размеры; их общие стили включены в критический CSS.
- Основной variable Inter уменьшен с 352240 до 120628 байт для латиницы/кириллицы. Остальные символы при необходимости загружаются из исходного шрифта. Скрипт воспроизведения: `scripts/subset-font.py` (fontTools и brotli).
- Предзагрузка маршрутов по взаимодействию вместо загрузки всех видимых ссылок; включено предварительное сжатие статических файлов.
- Возвращён pinch-to-zoom: прежний запрет масштабирования несовместим с проверкой доступности. Внешний вид приложения сохранён.

## Проверки

Typecheck, production build, SEO HTTP smoke, 278 unit-тестов и 107 браузерных тестов прошли; 3 браузерных сценария пропущены по условиям проектов. Новый тест проверяет геометрию до загрузки hero, отсутствие ошибок гидратации и единственный запрос рекомендаций при прокрутке.
