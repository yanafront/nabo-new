# Управление категориями рецептов

Откройте `/admin/recipes` → **Категории** (`/admin/categories`). Требуется существующий аккаунт редактора.

- Создание: название и уникальный адрес латиницей (`snacks`). Максимум 100 категорий, название до 80 символов, адрес до 40.
- Переименование: меняется название, адрес остаётся стабильным для сохранения ссылок.
- Удаление: возможно только если категория не используется ни в черновиках, ни в опубликованных версиях. Сначала назначьте другую категорию этим рецептам.
- В форме рецепта и отдельном действии изменения категории доступны текущие категории из БД. JSON-редактор также принимает новые `categoryId`.
- Публикация изменений рецепта по-прежнему отдельная операция. Быстрое изменение категории обновляет только категорию, не публикует остальные черновые поля.

Категории хранятся в общей БД сервиса `nabo-recipes`, таблица `nabo_recipes.recipe_categories`. Миграция запускается при старте сервиса; существующие категории переносятся один раз, переименованные/удалённые не восстанавливаются при перезапуске. Новые переменные окружения не нужны.

API:

- `GET /api/recipe-categories` — публичный список.
- `GET /api/admin/recipe-categories` — список редактора.
- `PUT /api/admin/recipe-categories/{id}` — `{ "title": "Закуски", "revision": 0 }` для создания, текущая revision для переименования.
- `DELETE /api/admin/recipe-categories/{id}?revision=...` — удаление неиспользуемой категории.

Мутации требуют авторизации редактора и текущей revision. Конфликты версии, адреса/названия и использования возвращают 409. Сохранение связей рецептов и удаление категорий согласованы транзакционным advisory lock PostgreSQL.

Каталог, H1, Recipe JSON-LD, ссылки категорий и sitemap используют динамический список. Публичный серверный кэш обновляется в течение минуты. Список в админке получается напрямую с бэкенда вместе с рецептами; для старого API сохранён совместимый начальный список до обновления сервиса.

Проверки: backend CI с PostgreSQL для CRUD, авторизации, конфликтов и сохранности черновика; `npm test`, `npm run test:seo`; браузерные `recipe-taxonomy`, `recipe-json`, `recipe-categories` на desktop и mobile.
