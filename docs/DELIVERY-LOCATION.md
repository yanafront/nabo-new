# Точка доставки

Модалка центрирована на всех ширинах. Геолокация запускается только по кнопке и требует разрешения браузера (HTTPS или localhost). Используются реальные координаты без округления, maximumAge=60000, enableHighAccuracy=false (быстрый поиск по Wi-Fi/сети). Точность показывается пользователю. При ошибке старые координаты не заменяются.

Поиск адреса выполняется только по кнопке/Enter через `/api/location/search?q=...`; выбор результата обязателен. Редактирование текста сбрасывает подтверждение и отменяет устаревший поиск. Без выбора сохранить введённый текст со старыми координатами нельзя. До сохранения глобальная точка не меняется. Сохранённые `{lat,lon,label}` уже передаются useApi в поиск, useRetail в сравнение и useRecipeBasket в подбор рецепта; localStorage сохраняет их для следующего посещения. Поиск товаров повторяется при смене точки.

По умолчанию используется публичный Photon / OpenStreetMap. Проверка показала, что русские названия белорусских улиц он может сопоставлять плохо; результаты требуется проверять, есть ссылка на карту. Покрытие и доступность демо-сервера не гарантированы: https://github.com/komoot/photon#demo-server. Сервер ограничивает частоту запросов в одном процессе. Это не глобальный лимит для нескольких serverless-инстансов. Для заметного трафика используйте собственный Photon (NUXT_GEOCODER_BASE) или коммерческий геокодер.

Для Минска и нескольких распространённых улиц используются проверенные белорусские варианты названий (`shared/address-query.ts`); номер дома сохраняется. Если локализованный запрос не дал результатов, проверяется исходный текст. Это ограниченный словарь, а не полная поддержка всех русских адресов. Координаты берутся только из ответа геокодера или выбора пользователя на карте. Ошибки поиска адреса и браузерной геолокации отображаются отдельно и сбрасываются при переходе к другому способу выбора точки.

Для поиска адресов через Яндекс задайте **серверную** переменную `NUXT_YANDEX_GEOCODER_API_KEY` в локальном окружении и Vercel, затем перезапустите/пересоберите проект. Ключ не помещается в public runtimeConfig и не отправляется браузеру. При настроенном ключе адреса запрашиваются в официальном API с ru_RU и ограничением на Беларусь, ошибки ключа показываются как недоступность поиска. Реальный запрос Яндекса без ключа не проверен; контракт покрыт тестом.

Документация Яндекс: https://yandex.ru/maps-api/docs/geocoder-api/request.html

## Карта в модалке

Интерактивная карта позволяет выбрать точку кликом или перетаскиванием метки; координаты сразу становятся черновиком, а в запросы попадают после «Использовать эту точку». Поиск адреса и геолокация перемещают ту же метку. Редактирование адреса удаляет метку и запрещает сохранение старых координат. Выбор на карте отменяет устаревшие запросы и колбэки геолокации.

`NUXT_PUBLIC_YANDEX_MAPS_API_KEY` включает официальный JS API Яндекса 2.1. Для ключа нужны разрешённые домены localhost и production; публичность ключа JS API штатная, серверный ключ Геокодера не публикуется. После добавления публичного ключа требуется сборка и перезапуск. Без ключа или при ошибке загрузки Яндекса работает Leaflet/OpenStreetMap — это обозначено под картой. Публичные тайлы загружаются только для текущего вида, без предварительного скачивания или серверного прокси. Атрибуция сохраняется.

Геолокация теперь ограничена 8 секундами и допускает данные браузера не старше минуты. Таймаут не блокирует выбор на карте. «Точка на карте» означает выбранные координаты, а не подтверждённый почтовый адрес.
